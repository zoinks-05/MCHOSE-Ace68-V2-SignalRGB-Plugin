# MCHOSE Ace 68 V2 – SignalRGB

Custom SignalRGB support for the **MCHOSE Ace 68 V2** mechanical keyboard.

**Features**
- Individually mapped hardware LEDs.
- SignalRGB Canvas lighting support.
- Custom static colour mode.
- Configurable shutdown colour.
- Hardware LED testing mode.

## Compatibility

| | |
|---|---|
| Device | MCHOSE Ace 68 V2 |
| Vendor ID | `0x3837` |
| Product ID | `0x3024` |
| Software | SignalRGB |

**Note:** Designed for the standard Ace 68 V2. Support for the **Ace 68 V2 Air is untested and not guaranteed**. Please refer to the documentation or create your own device script if your keyboard is unsupported.

## Installation

1. Open **SignalRGB**.
2. Navigate to **Add-on Manager**.
3. Select the option to install an add-on from a GitHub URL.
4. Paste the repository URL:

   `https://github.com/zoinks-05/MCHOSE-Ace68-V2-SignalRGB-Plugin`

5. Confirm the installation.
6. Restart SignalRGB if required.

Once installed, your MCHOSE Ace 68 V2 should be detected and ready for RGB control.
